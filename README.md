# 知漪 · murRipple — 成品演示

把一首歌织成看得见的涟漪。

**▶ 在线播放：** https://ymustc.github.io/murripple-demo/

这个仓库只存放成品页面（单个零依赖的 `index.html`，音频与数据全部内嵌）。
源码在另一个仓库，尚未公开。

## 怎么玩

- 点击「开始」后有约两秒的解码等待（四轨 AAC）
- **空格**暂停 / 继续
- **点走带条**任意位置跳转，**按住拖拽**可以来回擦洗
- 右侧四个按钮**单独静音**人声 / 鼓 / 贝斯 / 其他，旁边六条是各轨道的实时电平
- 右上「下载」把这个页面本身存下来，离线也能看
- 想要干净画面时按 **H**（或点走带条右端的 ⌄）收起界面，再按 H 或点画面任意处就回来

也可以下载 `index.html` 双击本地打开，不需要联网。

## 画面里都是什么

| 位置 | 是什么 |
|---|---|
| 中心发光的字 | 歌词本身就是光核，随人声强弱呼吸 |
| 内圈起伏的曲线 | 径向波形，直接从音频取样 |
| 中间那道亮环 | 判定环，人声在场时点亮 |
| 环外的密集短线 | 频谱，按对数分频、左右镜像 |
| 从外圈坠向亮环的光点 | 音符，提前 1.7 秒出现；低音按音高微调落点 |
| 命中时爆开的光屑 | 每次击中判定环时发射 |
| 最外圈六段彩弧 | 六条视觉轨道：撼岳 / 裂帛 / 碎玉 / 渊鸣 / 流岚 / 缥缈 |
| 环外密集短线 | 132 根频谱冠线，向外发散 |
| 每小节弹开的淡环 | 小节涟漪 |
| 段落切换时的大字 | 段落名，由 overrides.json 手写 |
| 命中时环上闪出的弧 | 命中冲击弧 |
| 换段时扫过一圈的光 | 换段光扫 |
| 环外的小字 | 声部铭文，视频里也有 |
