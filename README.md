# 知漪 · murRipple — 成品演示

把一首歌织成看得见的涟漪。

**▶ 在线播放：** https://ymustc.github.io/murripple-demo/

这个仓库只存放成品页面（单个零依赖的 `index.html`，音频与数据全部内嵌）。
源码在另一个仓库，尚未公开。

**这首歌**：《Trempe-moi》，3 分 58 秒，法语。音乐由 Suno 生成，歌词由 YU Miao
创作，**版权归他本人**。它同时是这套工具的第一首非中文素材。

## 怎么玩

- 点击「开始」后有约两秒的解码等待（四轨 AAC）
- **空格**暂停 / 继续
- **点走带条**任意位置跳转，**按住拖拽**可以来回擦洗
- 右侧**七行声部面板**：点一行静音它所属的声部，悬停会高亮环上对应的那段弧
  - 面板行数跟着实际分轨数走。这首歌是七行；
    其中**「撼岳」「裂帛」「碎玉」三行共用同一条鼓分轨**，点任意一行另外两行会一起暗——
    那是音源分离只能从成品音频里拆出四条的限制。**面板上这几行用竖脊连着**，
    不点也看得出它们是连动的
- 底部 **⇩ 混音**：按当前的静音状态导出一份混音 WAV
- 底部 **⤓ 下载**：把这个页面本身存下来，离线也能看
- 想要干净画面时按 **H**（或点走带条右端的 ⌄）收起界面，再按 H 或点画面任意处就回来

也可以下载 `index.html` 双击本地打开，不需要联网。

## 画面里都是什么

| 位置 | 是什么 |
|---|---|
| 中心发光的字 | 歌词本身就是光核，随人声强弱呼吸 |
| 内圈起伏的曲线 | 径向波形，直接从音频取样 |
| 中间那道亮环 | 判定环，人声在场时点亮 |
| 环外的密集短线 | 频谱，按对数分频、左右镜像 |
| 从外圈坠向亮环的光点 | 音符，提前 1.7 秒出现；低音按音高微调落点 |
| 命中时爆开的光屑 | 每次击中判定环时发射 |
| 最外圈六段彩弧 | 六条视觉轨道，与右侧声部面板一一对应 |
| 每小节弹开的淡环 | 小节涟漪 |
| 段落切换时的大字 | 段落名 |
| 命中时环上闪出的弧 | 命中冲击弧 |
| 换段时扫过一圈的光 | 换段光扫 |
| 环外的小字 | 声部铭文，视频里也有 |
| **右上角一串行星** | 六星连珠。不闪烁——恒星才眨眼，行星不会 |
| **偶尔划过的细线** | 英仙座流星。平均十几秒一颗，都从左上同一个辐射点射出 |

## 关于夜空

流星与行星是这一版新加的。两样都遵守这个项目的技术主线——**画面必须是时间
`t` 的纯函数**：流星的进度写成 `((t / 周期 + 相位) mod 1)` 这样的闭式，行星
的漂移与自转是 `sin(t · 系数)`，都不在逐帧渲染里累加状态。所以网页里看到的
每一帧，和离线逐帧导出的视频里那一帧，是同一帧。

行星画成球而不是亮点，靠的是**明暗交界线**：一个带交界线的圆是球，一个均匀
发亮的圆是光斑。没有这条线，它们和画面里下落的光屑就分不开了。
